# DESIRES

- Extended precision arithmetic (quad precision) in the Fourier solver would allow non-trivial branch residuals below 1.96e-16
- Ability to specify multi-mode initial guesses (e.g., a₁cos(θ) + a₂cos(2θ) + a₃cos(3θ)) in config
- Configurable dealiasing ratio (M/N) instead of hardcoded M=2*N
